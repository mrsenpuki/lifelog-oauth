lifelog

個人の記録を、本人のPCで整理するためのアプリです。

概要プライバシーポリシー利用条件連絡先

概要

lifelogは開発者本人が自分の記録を整理するために作った個人用のアプリです。一般の利用者に向けたサービスではなく、アカウントの発行も行いません。

Googleアカウントとの連携では、本人が認可したアカウントから次のデータを読み取り、本人のPCに保存します。

  • Googleフォーム：本人が指定したフォームの設問と回答
  • Googleドライブ：本人が指定した専用フォルダーに置いたJSONファイル
  • Googleカレンダー：本人が指定したカレンダーの予定

プライバシーポリシー

利用するGoogle APIの範囲

スコープ用途
forms.responses.readonly
forms.body.readonly		指定したフォームの設問と回答を読み取ります。
forms.body本人が明示的に操作したときだけ、フォームの作成や設問の更新に使います。通常の取り込みでは要求しません。
drive.readonly専用フォルダーのJSONファイルを読み取ります。Googleの仕様上はドライブ全体を閲覧できる権限ですが、アプリは設定した専用フォルダーだけを検索します。ファイルの書き込み・削除・共有設定の変更は行いません。
calendar.events.readonly指定したカレンダーの予定を読み取ります。予定の作成・変更・削除は行いません。

データの扱い

  • 取得したデータは本人のPC上のファイルとデータベースに保存します。開発者が運営するサーバーはありません。
  • 本人が設定した場合に限り、整理した結果を本人のクラウドストレージの同期フォルダーへ書き出し、本人が使うツールから参照することがあります。
  • 取得したデータを第三者に販売・提供したり、広告に使ったりしません。
  • Googleの認証情報（トークン）は本人のPCの設定領域に保存し、ソースコードや公開ファイルには含めません。
  • Google APIから取得したデータの利用は、Google API Services User Data Policy（Limited Useの要件を含む）に従います。

保存期間と削除

取得したデータは、本人が削除するまでPCに残ります。連携をやめるときは、Googleアカウントの「サードパーティのアプリとサービス」からlifelogへのアクセスを削除してください。アクセスを削除しても、取得済みのデータはPCから自動では消えません。必要に応じて本人が削除します。

利用条件

このアプリは開発者本人が使うためのものです。本人以外の利用は想定していません。動作の保証はなく、利用によって生じた損害について開発者は責任を負いません。

連絡先

このアプリとデータの扱いに関する問い合わせは、Googleアカウントの連携時に表示される同意画面のデベロッパー連絡先へお送りください。
